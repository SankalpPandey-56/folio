Enable Real Google Sign-In

Why is this step required?

To open the real accounts.google.com sign-in window, Google requires your web app to be registered in a Google/Firebase project. Google will never allow an unregistered app to trigger their login window (for user security and anti-phishing protection).

Quick 2-Minute Setup:

  1. Go to console.firebase.google.com ↗ and click Create a project.
  2. In Authentication > Sign-in method, enable Google.
  3. In Firestore Database, click Create database.
  4. In Project Settings (⚙️) > General > Your apps, click Web (</>) and copy the firebaseConfig object.
